## Known limitations and next evidence

- The analyzer supports a deterministic, model-free fallback; no API key is needed for this assessment mode. The [AI Decision Matrix](./ai-decision-matrix.md) documents its current decisions and limits. No autonomous multi-agent runtime or provider-backed result is claimed.
- The assignment requires at least five real prompt/output correction examples. Four conversational examples and one model-free RCA review decision are documented in [AI evidence](./ai-evidence.md); evaluator acceptance of the fifth candidate is uncertain. No fabricated provider-backed interaction is claimed.
- A previous no-retry rerun was 35/36 because of the public queue-full page; the latest one-worker/no-retry suite passed 40/40 with the site available. The explicit queue skip is covered by a synthetic-page test and was not triggered in the latest run. The smoke subset passed three consecutive times.
- The tracked RCA summary reflects the local 40/40 run with zero ordinary failures and two controlled-fault records. PR run #20 is documented separately: the owner approved the 10 explicit HTTP 403 response cases as third-party response failures, while 17 UI timeouts remain pending. Main run #21 passed 40/40 afterward; that recovery does not prove the cause of run #20.
- Prior GitHub retries and the later failed runs are recorded above and in the [RCA evidence package](./rca-package.md). The workflow now fails after artifact upload when a test passes only after a retry; current PR and manual runs verified the gate with no flaky tests.
- The rubric requires at least 85/100, RCA at least 14/18, and AI-agent design at least 11/15 for READY. This estimate reaches the total and AI-design gates but remains below the RCA gate.
- Do not claim Level-3 readiness until the RCA subscore gate and remaining prompt evidence are complete, any identified product fix is validated, and any additional evaluator-required CI evidence is available.
